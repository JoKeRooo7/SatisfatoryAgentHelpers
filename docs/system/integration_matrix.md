# Матрица взаимодействий с миром

Предлагаемая граница поддержки. Это покрытие классов взаимодействия, а не обещание доступа к непроверенным методам SDK. Каждая строка получает capability adapter: чтение, навигация, взятие/внесение, строительство, демонтаж. Наличие одного интерфейса не означает наличие остальных. Для стороннего объекта возможна только подтверждённая безопасная операция.

## Компоненты игры

| Группа | Что читают специалисты | Разрешённое действие после проверки адаптера | Конфликт / отказ |
| --- | --- | --- | --- |
| Обычные и промышленные контейнеры | Ёмкость, фильтры, подключения, доступные количества | Взять/передать зарезервированную партию, привязать нескольких ботов | Игрок/лента изменили остаток → пересчитать допустимое количество на authority; не дублировать предметы |
| Личные рюкзаки и ящики погибших | Физический груз, владелец, состояние | Доставить/собрать разрешённые предметы | Чужой ящик/доступ запрещён → заявка владельцу, без обхода прав |
| Конвейеры, подъёмники, разветвители и объединители | Направление, класс пропускной способности, соединения, фильтры | Анализировать; строить/удалять только утверждённый участок | Номинальная скорость не равна фактическому потоку; неизвестный модовый splitter остаётся неизвестным |
| Трубы, насосы, буферы, клапаны | Направления, высота/напор, тип жидкости, ёмкость и подключения | Анализ/строительство подтверждённой связки | Нельзя смешивать несовместимые жидкости, объявлять физику трубы обычным max-flow или сливать без учёта |
| Электросеть, опоры, кабели, накопители, генераторы, переключатели | Компоненты связности, доступная мощность, нагрузка, состояния | Подключение/перестройка по плану с контролем отключений | Разрыв питания активной фабрики требует окна работ и подтверждённого порядка; удаление ребра может разделить сеть |
| Производственные машины, плавильни, переработка | Активный рецепт, открытие, скорость, входы/выходы, питание | Снабжение и строительство; смена рецепта только отдельным разрешённым действием | Игрок поменял рецепт → старая оценка/план устарели; входы не принимаются на веру |
| Ресурсные узлы, залежи, шахтёры, скважины, экстракторы | Тип и доступность ресурса, занятость и оборудование | Доступная ручная добыча/проверенное оборудование | Майнер не получает право ручного сбора жидкости; занятый узел не разбирается автоматически |
| Растения и собираемые предметы | Доступность без инструмента, тип, количество, опасность пути | Сбор по фильтру, повторная проверка на подходе | Другая роль/игрок собрали раньше → завершить без добычи и выбрать следующую цель; редкие предметы по Q-007 |
| Мобы и их добыча | Доступные цели, агрессия/настройки мира, здоровье, риск | Бой/добыча по доступным игровым правилам | Нет оружия/боеприпасов/защиты → снабжение или другая работа; не бесконечная атака |
| Газ, радиация, вода, падение, высоты | Наблюдаемый урон, снаряжение, срок защиты, проходимость | Обход; вход только с подходящей защитой и запасом на обратный путь | Неизвестная опасность → пометка риска; медик не идёт погибать вслед за пациентом |
| Тракторы, грузовики, станции и маршруты | Назначение, топливо, расписание, груз, достижимость | Снабжение/обслуживание разрешённых стоянок | Игрок управляет/маршрут изменился → не перехватывать управление; телепортация груза запрещена |
| Железная дорога, поезда, станции, сигналы | Топология, расписание, занятость платформ и блоков | Анализ связности и загрузки; подтверждённая стройка отдельным этапом | Алгоритм не подменяет сигнализацию; неизвестный блок/обновление расписания инвалидирует предложение |
| Дроны и порты | Назначения, груз, подтверждённый вид топлива/энергии | Проверенное снабжение порта и анализ доставки | Перечень топлив зависит от версии; не зашивать выдуманную константу |
| Фундаменты, стены, двери, лестницы, пандусы, мосты | Коллизии, опоры, проходимость, доступные точки стыка | Стройка по шаблону и обновление графа проходов | Исчез опорный объект/дверь закрылась → стоп зависимым действиям и локальный пересчёт пути |
| Гипертрубы, прыжковые площадки, лифты и другие способы перемещения | Существование и подтверждённая возможность прохода | Только после отдельного movement adapter | Нет адаптера → маршрут ими не пользуется; бот не телепортируется через неизвестное ребро |
| HUB, MAM, этапы, исследования и рецепты | Подтверждённые открытия мира и ограничения | Использовать открытое; изменение прогресса только явным разрешением | Не завершать исследования, milestone, не тратить уникальные предметы без пользовательской задачи |
| AWESOME Sink, магазин и прочие расходующие системы | Контекст стоимости и риска потери ресурса | Только явный заказ/политика владельца | Автоматическое избавление от «лишнего» запрещено без определённой политики |
| Blueprint Designer и шаблоны | Размеры, состав, открытия, стоимость, точки подключения | Разворачивать проверенный шаблон по утверждённому плану | Недоступный/несовместимый blueprint → видимый отказ; не угадывать внутреннюю структуру |
| Пульт, площадка и косметическая капсула | Сохранённый StationId, слот посадки, жизненный цикл | Идемпотентное появление и восстановление | Снос одного объекта не убивает ботов, не обнуляет оплату и не создаёт повторную станцию на каждом входе |
| Планшет, инструмент привязок, знак-заглушка | Профиль клиента и его возможности | UI/привязка/подсказка в поддерживаемом профиле | Неизвестный сетевой item descriptor нельзя безопасно заменить одним изображением |
| Неизвестные объекты других модов | Только подтверждённые публичные данные | Разрешённые адаптером операции | Нет метода/плагин выгружен → отключить способность, сохранить задачи/груз и объяснить причину |

В игре нет обещанной «нашей» реализации ремонта транспорта или свободного крафта NPC. Эти действия требуют проверки доступной механики. Роль обслуживания может приносить пользу проверенным снабжением, не изобретая очки прочности для машин.

## Системные взаимодействия

| Событие | Обязательное поведение |
| --- | --- |
| Мир ещё загружается | Не сканировать частично готовые системы как пустые; дождаться lifecycle готовности |
| Actor выгружен streaming | Различать «не загружен» и «уничтожен»; хранить стабильный ID; действие в мире требует загрузки и проверки |
| Игрок переместил/снёс объект | Версия затронутого региона меняется; задачи с прежними предпосылками приостанавливаются; чужие области не пересчитываются целиком |
| Два бота хотят один предмет/слот | Authority выдаёт ограниченный резерв; физическое изменение проверяет остаток на момент commit |
| Планировщик передумал в пути | Отмена происходит на безопасной границе; груз остаётся физическим и получает задачу разгрузки |
| Один бот поручил действие другому | В графе один родитель и общий correlation key; cycle check и конечная глубина делегирования |
| Пульт снесён во время найма | Логическая заявка переживает косметику; новый spawn не добавляет второй BotId; выбор возврата/переноса по сохранённой стадии |
| Персонаж погиб в середине стройки | Освободить lease, материал в ящике; существующая постройка сверяется, остаток плана возвращается аналитику |
| Загрузка сохранения | Восстановить общую контрольную точку, сверить фактический мир, не повторять все физические операции только по старому журналу |
| Хост вышел | Нет внеигрового фарма; продолжение из последнего согласованного сохранения, перенос хоста — отдельная неподтверждённая возможность |
| Подключился новый клиент | Сначала проверка профиля/версий; затем снимок и обновления. Не отправлять неизвестные модовые данные неподдерживаемому клиенту |
| Потеря связи во время команды | Correlation ID и журнал результата устраняют дубли; повторный клик не означает новую оплату |
| Смена настроек мира | Пересчитать допустимость охоты, опасности, стоимости и маршрутов; локальная настройка клиента не меняет authority |
| Выключение мода | Не обещать безопасное удаление новых объектов/предметов из старого save без процедуры экспорта/разгрузки и отдельной проверки |

Критические интеграции проверяются по [плану QA](../testing/test_plan.md). После подтверждения SDK строка дополняется конкретными классами, версиями и тестом; текущий документ не создаёт вымышленных игровых API.
