# Требования первого решения

Источник — [полный исходный запрос](../first_prompt), сохранённый с исходными формулировками. Это спецификация будущего мода: ни одна строка таблицы не означает уже работающую возможность. Уточнения и предлагаемые политики вынесены в [решения](decisions.md). [Связь с исполнительными задачами](traceability.md) и планом QA сохранена; текущий этап — документы и декомпозиция.

## Граница обещаний

«Все компоненты» означает определённую матрицу возможностей и явное поведение для неизвестного, а не гарантию будущих версий любого мода. «Не простаивает» означает поиск полезной допустимой работы; бесцельное хождение, создание лишних контейнеров, трата редких ресурсов и поход в смертельную зону полезностью не считаются. Эти трактовки — предлагаемые правила безопасности и баланса для согласования перед соответствующей реализацией.
