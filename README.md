# SatisfactoryAgentHelpers

Локальный мод для Satisfactory: нанимаемые специалисты помогают со складами, переносом, сбором, добычей, охотой, снабжением, анализом фабрики и утверждённым строительством. Управление — через пульт с посадочной площадкой, планшет и отдельное окно настроек. Основа поведения — графы, очереди и конечные автоматы без обязательных моделей и внешних API.

**Текущий этап — первое проектирование. Исполняемого мода, сборки и подтверждённых игровых тестов пока нет.**

Начать реализацию: открыть последнюю контрольную точку TASKS и DEV-101, зафиксировать фактическую версию игры/SDK, затем выполнить изолированные технические проверки M0. Первый игровой сценарий M1 — найм одного переносчика, прибытие, физическая доставка между складами, наблюдение в планшете и корректная перезагрузка.

Поддержка полностью vanilla клиента и клиента только с SML исследуется отдельно. Ванильная модель предмета или табличка сами по себе не гарантируют подключение и безопасную репликацию. Пока эти режимы не заявлены рабочими; выбор допустимого варианта следует после эксперимента.

Репозиторий на GitHub фактически называется `SatisfatoryAgentHelpers` (без `c`); предлагаемое имя продукта и Mod Reference — `SatisfactoryAgentHelpers`. Переименования репозитория в этой ветке нет. Ветка по запросу: `feature/fitst_solution` от `develop`.
